Features

Everything you need for
reliable uptime monitoring

Built from scratch with production-grade security, real-time alerts, and zero configuration overhead.

🔐

JWT Authentication

Stateless authentication with JJWT. Session management via Redis with automatic expiry and refresh token rotation.

📧

Email OTP Verification

Every account verified via email OTP before creation. No fake accounts, no spam — only verified users get alerts.

🔑

Google OAuth2

One-click sign in with Google SSO. Spring OAuth2 handles the entire flow — no passwords needed.

📡

60-Second Monitoring

Scheduled pinger checks all URLs every 60 seconds using a 20-thread pool. Response time, status, and timestamps tracked.

🔔

Instant Alerts

Get an email the moment your site goes down — and another when it recovers. Powered by transactional email API.

⚡

Alert History

Full audit trail of every status change. See when monitors went down, when they recovered, and response times over time.

How It Works

Up and running in
three simple steps

01

Create Your Account

Sign up with email + OTP verification or use Google OAuth2 for instant access. Your email is where alerts get delivered.

POST /api/auth/send-otp
02

Add Your Monitors

Add any URL you want monitored. Each user manages their own list. Add as many as you need — we check them all.

POST /api/monitors
03

Get Instant Alerts

Sit back. Every 60 seconds we check your URLs. If something goes down — you'll know within a minute via email.

GET /api/monitors
